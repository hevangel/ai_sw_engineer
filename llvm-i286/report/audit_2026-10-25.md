# Audit record — llvm-i286, 2026-10-25

Stage-1 record for hevangel/ai_sw_engineer#66 (America/Vancouver date).

## What exists now (this folder)

- `spec/audit_upstream.md` — no upstream or maintained-fork LLVM/rustc i286
  support; gcc-ia16 (GCC 6.3.0 port, GPL, `-march=i286`, partial protected
  mode) and Open Watcom are the existing C toolchains; the community Rust
  recipe (`i386-unknown-none-code16`) emits 386 instructions and cannot run
  on a 286. Sources linked inline, audited 2026-10-25.
- `spec/machine_profile.md` — PC AT 5170 compiler contract: real mode first,
  protected mode second; 386+ instructions forbidden; 16:16 segmented data
  layout; MZ/COM/flat/option-ROM package formats; integer-only default ABI
  (80287 as an optional profile).
- `plans/implementation_plan.md` — five milestones (spec freeze → MC →
  CodeGen → runtime/linker → Rust profile) on the llvm-i4004 route.
