# Shared reference material

Manuals, datasheets and ISA references used by more than one title or backend. Title-specific material goes in that title's `spec/`.

Every file gets an entry here: title, what it is used for, source URL, size and SHA-256. Copyrighted material that is not freely redistributable is recorded here but not committed (add it to `.gitignore`).

Many manufacturer references already live in the sibling [ai_hw_engineer/references](https://github.com/hevangel/ai_hw_engineer/tree/main/references) (MCS-4 data sheet, 8008 user's manual, Apple IIe TRM, Intel peripheral handbook); cite them there instead of duplicating.
