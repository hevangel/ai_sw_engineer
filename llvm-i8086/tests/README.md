# llvm-i8086 tests

- `mc/` — the assembler, disassembler and object writer (`lit` + FileCheck):
  - `encodings.s` — 188 instructions with the bytes the Intel 8086 Family User's Manual's opcode table gives, generated by `gen_encodings.js` from a table written by hand from that manual
  - `disasm.txt`, `disasm-invalid.txt` — decoding, prefixes, alternative encodings, rejection of 80186+ and undocumented bytes
  - `relax.s`, `range.s` — branch relaxation and out-of-range short jumps
  - `fixups.s` — relocation kinds, addends, ELF machine number
  - `errors.s` — diagnostics
  - `vector_check.py` — every instruction form against the physical-chip corpus (below)
- `codegen/` — `llc` output checked with FileCheck: instruction choice, addressing modes, frames, calls, branches (milestone 3)
- `run/` — `.ll` programs compiled to ELF objects (`scripts/gen_run_objects.sh`, committed as `*.o`), linked by a small linker in `system/ibm_pc/emulator/tests/i8086_codegen.rs`, called with the ABI of `spec/abi.md` on the 8088 core, and compared with the same computation on the host (not lit tests)
- `smoke/` — small programs run on the simulator with expected final state (milestone 7)

`vector_check.py` is the independent opcode table: SingleStepTests/8086 lists the
exact bytes and MartyPC's disassembly of thousands of random instances of every
opcode, captured from a real chip. It checks that each decodes with the right
mnemonic and nothing left over, and that the printed text assembles back to the
same bytes (or to an alternative encoding that disassembles identically).
Run all with `scripts/run_tests.sh`.
