# llvm-i8008 test plan

| Suite | Tool | Oracle | Location | Image |
|---|---|---|---|---|
| MC encode | `llvm-mc -show-encoding` + FileCheck, every opcode | MCS-8 opcode table (`spec/isa.md`), generated by `gen_encodings.py` | `tests/mc/` | ai-sw-engineer |
| Disassembly | `llvm-objdump` + FileCheck | same table | `tests/mc/` | ai-sw-engineer |
| Codegen | `llc` + FileCheck | hand-checked expected asm | `tests/codegen/{alu,mem,call,branch}.ll` | ai-sw-engineer |
| Execution | `scripts/exec_tests.py N`: each `rt/` helper and N random cases per IR operation (i8/i16 ALU and compares), compiled and run on the RTL | Python models of the operations | generated | ai-hw-engineer |
| Rust end-to-end | `tests/smoke/hello` on the RTL | its known output | `tests/smoke/` | both |
| Titles | the Micral N titles' oracle transcripts on the RTL | the original programs | `system/micral_n/*/scripts/run_sim.sh` | ai-hw-engineer |

Every helper's execution test passes its arguments in the registers llc
uses for a call to it, and fills the others with junk
(`failure_notes/2026-10-24-i8008-memset-value-register.md`).

Size gate: each title's image is linked and measured on every backend change
(`system/micral_n/basic/report/size_history.md`).
