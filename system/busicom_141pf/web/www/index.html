This mode would execute the actual ai_hw_engineer SystemVerilog machine through the HDL Workbench/Xezim adapter — slower than the default, with internal signal inspection and waveforms. It is not available yet:

  • Xezim adapter qualification (ai_hw_engineer#69) is pending.
  • Shared Workbench/public-system adapter integration (ai_engineer#55) is pending.
  • Surfer waveform integration (ai_hw_engineer#68) is pending.

The default Rust/WebAssembly machine does not depend on any of this. Switch the selector back to use it.
