# Original software used by the emulator tests

None of these is in this repository. They are IBM and Microsoft firmware and
media, copyrighted. The tests read them from `$IBM_PC_ROMS` or from the
hardware project's cache and check their SHA-256 first.

| File | What | Bytes | SHA-256 |
|---|---|---:|---|
| `bios.bin` | IBM 5150 BIOS, 1981-04-24 | 8,192 | `a259306c47b43e14ef6378d7bdeff67331a2519d363bc36b3f354bc91a6874c8` |
| `basic.bin` | IBM Cassette BASIC 1.00 (ROM) | 32,768 | `2452b03b4b724b5b81e8cc367809c521144f5fe4e0425caee42ac71240b9b102` |
| `pcdos100.img` | IBM PC DOS 1.00 system diskette, 160 KiB | 163,840 | `29a4c5eb355b2bfb1dbbece96d91eabc5c1331c6299437d00dd8d862ac126eb2` |
| `workdisk.img` | blank formatted FAT12 work diskette, generated by the hardware project (no copied OS files) | 163,840 | generated, not pinned |

Source and conversion: the hardware project fetches the BIOS and BASIC from the
[PCjs](https://github.com/jeffpar/pcjs/tree/1a91d38eb12e5fdf91116b21ad9ef1935710a496)
archive revision `1a91d38eb12e5fdf91116b21ad9ef1935710a496` and PC DOS 1.00 from the
[PCjs diskette archive](https://github.com/jeffpar/pcjs-diskettes/tree/cd3433748b09837a4c60ca7066f3642772b2d711/pcx86/sys/dos/ibm/1.00)
revision `cd3433748b09837a4c60ca7066f3642772b2d711`, validates Git blob IDs and converts the
container formats to flat bytes without patches. Run
`system/ibm_pc/scripts/prepare_images.py` in `ai_hw_engineer` to fill
`system/ibm_pc/work/reference/`. The hashes above are that project's recorded
values (`system/ibm_pc/spec/reference/README.md`).

License status: IBM BIOS, Cassette BASIC and PC DOS 1.00 remain under their
original copyrights; they are fetched into an ignored local cache and never
committed. The recorded screen transcripts in `../oracle/transcripts/` contain
only the text those programs displayed (prompts, a directory listing of file
names and sizes, CHKDSK totals).
