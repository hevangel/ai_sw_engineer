IBM PC 5150

The project's Rust whole-system emulator compiled to WebAssembly, running in your browser.

SystemVerilog backend unavailable

This mode would run the actual SystemVerilog IBM PC from the hardware project through the HDL Workbench/Xezim adapter, with signal and waveform inspection. That adapter is not qualified or available to this page yet (hevangel/ai_engineer#80, hevangel/ai_engineer#55), so nothing runs in this mode and no signals are shown. The Rust emulator is not a simulation of the RTL and is not presented as one.

Switching backends resets the machine.

1. Load the machine's ROMs and disks

IBM's firmware and PC DOS are copyrighted and are not included. Use your own copies; the page checks each file's SHA-256 against the recorded originals. Files stay in your browser.

2. Run

Click or focus the screen to type: keys go to the PC (Tab and Esc too). Press Ctrl+] to give the keyboard back to the page. Arrows, Home/End, PgUp/PgDn, Ins/Del are the PC's numeric-pad keys.

Machine off.

Debugger (registers, step, breakpoints, memory)

Commands are the native --monitor's: r, s [n], t [n], g [steps], b SSSS:OOOO, bc, bl, d SSSS:OOOO [len], screen, ?. Numbers are hex. Pause the machine first to inspect a stable state.
