Backend

The SystemVerilog backend would run the hardware project's RTL with signal inspection; it is not available yet.

SystemVerilog backend unavailable

This mode would run the actual SystemVerilog IBM PC from the hardware project through the HDL Workbench/Xezim adapter: much slower than the Rust emulator, but with internal signals and waveforms to inspect. That adapter is not qualified or available to this page yet (hevangel/ai_engineer#80, hevangel/ai_engineer#55), so nothing runs in this mode and no signals are shown. The Rust emulator is not a simulation of the RTL and is not presented as one.

Switching backends resets the machine.

About this machine

        
IBM 5150 board as the hardware project models it: 8088 at 4.77 MHz, 64 KiB RAM, CGA,
          two single-sided 160 KiB drives, speaker. Timing is per instruction, not per cycle.
          Not modelled: cassette, printer, serial, game port, more RAM.
